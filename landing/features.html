FEATURES · 能力清单

每个 Subagent，
各司其职。

十项能力，六章讲完：从独立角色到绩效闭环，全部在官方 CLI 之上原生运行。

设计
SUBAGENTS · 独立角色与模型分工

每个 Subagent，都有自己的角色、模型与上下文。

名册里每位成员都是具名工程师：独立 role、独立 model、独立上下文窗口。模型分工用 [subagent.model_overrides] 三级优先配置，主模型按职责派工。

PARALLEL DISPATCH · 后台并行派工

派工默认后台并行。

主模型派工即建 Agent / AgentSwarm 任务，默认后台并行执行；Agent 池满时任务入队等待，standby 成员按权重加权选人，不空转、不阻塞主流程。

TEAMSCORE · 绩效与通胀检测

分数记账，通胀无处遁形。

每位成员按 0–100 记账：连续高分触发通胀检测，异常扣分入账，未计分引擎主动提醒。

TeamScore 记账 · 真实输出
[TeamScore] Scored "yan-ge" — 88/100.
Score inflation detected: the last 5 scores for yan-ge are all >= 75...
[TeamScore] Penalized "yan-ge" — deducted 15 points (recorded 85/100).
ACCEPTANCE GATE · score_gate 硬门禁

不达标，不放行。

score_gate 作为验收硬门禁：未达到阈值的任务被拦截，低质量结果不会继续扩散。

门禁拦截 · 真实输出
[TeamScore] Blocked by acceptance gate
ROSTER · 具名名册与三态生命周期

谁在干活，谁在休息，一目了然。

具名工程师名册 + 三态生命周期：working / resting / off-duty。/team 面板实时呈现每位成员的岗位、模型、均分与当前状态。on-duty（本会话未出勤）与 off-duty（已归档）在界面上统一显示为「下班」。

SKILLS & MEMORY · 技能注入与停靠复用

会技能，也记得住。

技能体系走两级 pipeline 注入 + model-roster；memory 与停靠复用（KV-cache 保活、TTL 2h）让成员记得上轮上下文。TUI 与 Web 双形态，onboarding 冷启动 4 问即可「组建我的团队」。

十项能力，六章讲完。

从独立角色到绩效闭环，装好即可体验。
