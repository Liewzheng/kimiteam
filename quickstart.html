部署

QUICKSTART · 安装 → 组队 → 派工

一条命令，
装好一支团队。

三种安装方式任选其一；装完运行 kimiteam，4 问组队即可派工。

安装

INSTALL · 三选一

装到官方 kimi 旁边。

bash · 一键脚本（macOS / Linux）推荐 · 你的系统
curl -fsSL https://raw.githubusercontent.com/Liewzheng/kimiteam/main/scripts/install-kimiteam.sh | bash

自动下载 Release kimiteam-dev 最新分发，安装到官方 kimi CLI 旁；官方二进制与 bundle 原样保留。

powershell · Windows（irm 短链）推荐 · 你的系统
# 方式 1 · irm 短链
irm https://liewzheng.github.io/kimiteam/install.ps1 | iex
# 方式 2 · raw 长链（备选）
irm https://raw.githubusercontent.com/Liewzheng/kimiteam/main/scripts/install-kimiteam.ps1 | iex
# 方式 3 · 下载后以 -File 运行
powershell -ExecutionPolicy Bypass -File install-kimiteam.ps1
Release · 手动下载
# 资产清单
main-team.cjs
dist-web.zip

从 kimiteam-dev 发布页下载资产（main-team.cjs + dist-web.zip），解压到官方 kimi 旁即可。 打开 Release 页

验证

FIRST RUN · 组队与验证

首跑，组队，验证。

bash
kimiteam   # 首跑：冷启动 4 问，组建你的团队
kimiteam --version   # 验证版本

运行 kimiteam完成冷启动 4 问后，用 kimiteam --version验证安装版本。

团队就绪？

4 问组队后，主模型就开始后台并行派工。
