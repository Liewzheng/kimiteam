With team mode on, subagents default to running in the background — the tool returns immediately with a `task_id`, and the completion arrives in a later turn as a synthetic user-role message. No polling or sleeping needed during the wait. Only set `run_in_background=false` (foreground) when your next step cannot proceed without the subagent's result. Never launch in the background and then immediately wait on it (by polling `TaskOutput`, sleeping, or otherwise): that just blocks the turn for no benefit — run it in the foreground instead.
